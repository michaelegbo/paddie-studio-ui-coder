## Description

Paddie Studio is a desktop AI coding workspace for building real software while keeping the work visible. It brings chat-based coding, source editing, live preview, template-driven UI references, workflow generation, Paddie Memory, and Knowledge Base/RAG context into one connected Studio.

Build with an AI workspace that can see your project, edit real files, run commands, inspect previews, and reuse product patterns. Paddie Studio is built on opencode and adds Paddie-specific Studio tools around the coding loop so you can move from idea to working project with less context switching.

Templates help you start from stronger UI. Browse Paddie templates, preview polished screens and app starters, attach a full template or a selected part, then ask the AI to adapt the structure, spacing, hierarchy, typography, and motion intent to your current project.

Workflow Builder connects app logic, AI, APIs, memory, and RAG visually. Design workflow agents with nodes for webhooks, AI calls, conditions, API actions, Memory, Knowledge Base/RAG, and outputs, then export or integrate the generated code into your application.

Paddie Memory gives agents durable context for users, sessions, projects, preferences, and long-term knowledge. Knowledge Base/RAG lets you upload documents, build scoped knowledge bases, and retrieve grounded answers that your workflows and applications can call through APIs.

Native Autopilot turns larger requests into managed runs. It can plan the work, break the goal into tasks, choose relevant Studio tools, run scoped coding worker sessions, verify with tests or preview checks, and summarize what changed.

Use Paddie Studio when you want AI coding, visible UI building, templates, workflow automation, memory, RAG, and real project files in one desktop surface.
